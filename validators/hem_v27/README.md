# HEM v27 Validator

## Purpose

HEM v27 is the Reproducibility, Likelihood & Physicality Gate for early-universe/recombination implementations. It is independent from Tech-Orb Foundation canon.

## Starting State

HEM v26.4 is classified as a `[DERIVED][HISTORICAL][REPRODUCIBLE]` CLASS-level sensitivity/degeneracy experiment after R0. Its `H0` acoustic-angle lock is not a posterior, theory-to-theory TT RMS is not a likelihood, and the run does not establish a viable PMF/magnetogenesis model.

## Canonical Gates

R0 Reproducibility Freeze → R1 Baseline Definition Audit → R2 Published Model Reproduction → R3 Full Multi-Probe Likelihood → R4 Physicality Benchmark.

The detailed, controlling protocol is [GATE_PROTOCOL.md](GATE_PROTOCOL.md).

## Verdict Separation

Each gate records:

- **Pipeline verdict:** PASS / FAIL / BLOCKED / NOT STARTED.
- **Model verdict:** SURVIVES / DISFAVORED / EXCLUDED / UNDETERMINED / NOT APPLICABLE.

A pipeline can PASS while a model is excluded or returns `H0 ≈ 69`. `H0 > 71` is not a success criterion.
